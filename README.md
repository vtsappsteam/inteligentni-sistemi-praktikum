# Inteligentni sistemi, sveske sa zadacima

Sveske za laboratorijske vežbe iz predmeta Inteligentni sistemi, master strukovne studije Informacione tehnologije i sistemi, Akademija tehničko-vaspitačkih strukovnih studija, Odsek Niš.

Lekcije sa objašnjenjima, očekivanim rezultatima i rešenjima nalaze se na adresi https://isatvss.surge.sh. Svaka sveska se otvara u Google Colab-u dugmetom na stranici vežbe.

Sveske se generišu iz izvora praktikuma i ne menjaju se ručno u ovom repozitorijumu.
